# 🏠 阅读台（Reading Hub）

> 工作区的阅读首页，面向 **Obsidian 1.9+**（用到 Bases 功能）。
> 它不是静态清单，而是实时查询：新文件落盘自动出现，读完标注自动归位。

> [!tip] 💡 全局交互阅读功能已激活
> 点击下方表格中的任意文章直接打开阅读，在正文中即可享受：
> 1. **选词即划线**：鼠标选中文本，直接点击浮出的 🟡黄 / 🟢绿 / 🔵蓝 / ✍️下划线 / 𝗕加粗 高亮标记；
> 2. **写想法/批注**：选词点击 💬批注，记录灵感与思考；
> 3. **顶部状态流转**：文章正文顶部常驻 `未读` `已读` `精读` `跳过` 药丸按钮，点击即刻回写属性，本页表格实时自动同步！
> 4. **AI 深度速读**：文章正文顶部一键 `✨ AI 总结`，即刻提炼核心观点与启示。

## 怎么用

1. 每天打开本页，先扫「🎯 今日看什么」（近 3 天新内容）。
2. 读完一篇，在文章顶部 Properties 添加 `read_status`，填 `已读` / `精读` / `跳过`。
3. 已读和跳过会自动从待读视图消失；`精读` 进入收藏清单。
4. 全部 14 个视图 → 打开 [[reading-hub.base]]。分四组：**入口与监控**（今日看什么 / 日报监控 / 假设复盘 / Inbox）→ **播客流水线**（候选 → 已选 → 已转录 → 已发布）→ **内容库**（研究 / 筛选 / Wiki / Sources）→ **复盘**（精读 / 最近已读）。
5. 视频切片制作 → 在下方「🎬 杂志短视频切片工坊」展开可视化操作，或打开 [[magazine-studio|🎬 独立全屏工作台]]。

> [!note] 两个「入口」的区别
> - **🎯 今日看什么** = **全库**近 3 天新入库 + 未读/未跳过的汇总（跨目录收件箱），回答「今天有什么新东西」。
> - **🎯 播客候选** = 只管 `output/podcast-picks/`，回答「播客待办里有哪些还没做」。
> - 新落盘的播客卡片会**同时出现在两处**，用途不同、不冲突。要判断某集讲什么，看「播客候选」的**摘要**字段即可，不必跳转。

## 🎯 播客选品（候选 → 已选 → 已转录 → 已发布）

![[reading-hub.base#🎯 播客候选]]

> **看内容**：候选视图**以播出日期为类别**——每天一条标题栏（如 `2026-09-12`），**默认全部收起**，一眼看完有多少天、每天几集，不用往下拖。
> **点日期标题展开**，就能看到当天每一期的：中文标题 + 节目 / 嘉宾 / 时长 / 是否有转录稿 + 中文摘要 + 「原文 ↗」源地址。
> 顶部有「全部展开 / 全部收起」；**展开状态会记住**，下次打开还是那样。
> **浅读**：点标题打开笔记，正文有「一句话摘要」+「英文原文」。
> **深读**：点「原文 ↗」去 YouTube / 播客原页；或让我拉 BidClub 的完整转录稿。
>
> **推进状态**（三种方式，任选）：
> 1. 打开笔记，点顶部绿色「**选品：**」药丸（🎯 候选 / 📌 已选 / 📝 已转录 / 🚀 已发布）——最快；
> 2. 右侧栏「📊 笔记与阅读状态」卡片里的「选品：」药丸；
> 3. 直接改 Properties 里的 `pick_status`。
>
> 改完回看板，条目会**自动在四个视图间归位**。
> 完整四阶段视图 → 打开 [[reading-hub.base]] 看「🎯 播客候选 / ✅ 已选待转录 / 📝 已转录 / 🚀 已发布」。
>
> ⚠️ 状态**只是标记**，不会自动触发转录或发布——真正的活儿由 `podcast-to-wechat-workflow` 跑。
